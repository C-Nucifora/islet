# Islet M3 Implementation Plan — Sneak System + Battery

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Executed inline (subagents unavailable this session).

**Goal:** Transient "sneak" presentations in the compact island (charger events, track changes) driven by a coalescing queue, plus a battery activity fed by IOKit power-source notifications.

**Architecture:** A pure `SneakLogic` (tested) wrapped by a `@MainActor SneakQueue` that owns timing and suspension; sneaks temporarily override the compact slots in `NotchRootView`. `BatteryMonitor` (IOKit run-loop source) feeds `BatteryState` snapshots through a pure `BatteryEventDetector` (tested) into sneaks + a persistent charging indicator (`BatteryActivity`, ambient priority).

**Tech:** IOKit.ps, existing activity/notch infrastructure. Spec §5 (sneaks), §6.2 (battery).

## Global Constraints

- Same as M1/M2 plan: macOS 26, Swift 6, XcodeGen regen after adding files, formatter hook uses 2-space indent, commit per green cycle, no Claude trailers.
- Sneaks NEVER present while the island is expanded (hold and drain after close).
- Battery event detection must fire once per threshold crossing (20%, 10%), not repeatedly.

### Task 1: SneakLogic + SneakQueue

**Files:** Create `Islet/Activities/Sneaks/Sneak.swift`, `Islet/Activities/Sneaks/SneakQueue.swift`; Test `IsletTests/SneakLogicTests.swift`

- `Sneak`: `source: String` (coalescing key), `duration: TimeInterval` (default 2), `leading/trailing: AnyView`. Equality/identity by `source` + a UUID.
- `SneakLogic` (pure): `pending: [Sneak]`; `mutating func enqueue(_:)` — replaces a pending sneak with the same `source`, else appends; `mutating func popNext() -> Sneak?` FIFO.
- `SneakQueue` (@MainActor ObservableObject): `@Published private(set) var current: Sneak?`, `var isSuspended: () -> Bool` (wired to `vm.state.isExpanded`), `func submit(_:)`, presentation loop: pop → set `current` → sleep duration → clear → 0.25 s gap → next; while suspended, retry every 0.2 s without popping.
- Tests (pure logic): FIFO order; coalescing replaces pending same-source in place; distinct sources both kept; popNext empties.

### Task 2: Render sneaks in the compact island

**Files:** Modify `Islet/UI/NotchRootView.swift`, `Islet/App/IsletApp.swift` (debug menu), `Islet/App/AppDelegate.swift`

- `NotchRootView` observes `SneakQueue.shared`. ### Task 3: BatteryState + BatteryEventDetector (pure, tested)

**Files:** Create `Islet/Activities/Battery/BatteryState.swift`; Test `IsletTests/BatteryEventDetectorTests.swift`

```swift
struct BatteryState: Equatable {
    var percent: Int = 100
    var isCharging = false
    var onAC = false
}
enum BatteryEvent: Equatable {
    case acConnected(percent: Int)
    case acDisconnected(percent: Int)
    case lowBattery(threshold: Int, percent: Int)
}
enum BatteryEventDetector {
    static func events(from old: BatteryState?, to new: BatteryState) -> [BatteryEvent]
}
```
- Rules: `onAC` false→true ⇒ `.acConnected`; true→false ⇒ `.acDisconnected`; percent crosses down through 20 or 10 while not on AC ⇒ `.lowBattery` (old must be strictly above the threshold — fires once per crossing); `old == nil` ⇒ no events (baseline only).
- Tests: connect, disconnect, 21→20 fires, 20→19 does not re-fire, 11→9 fires threshold 10, crossing while on AC does not fire, nil baseline silent.

### Task 4: BatteryMonitor (IOKit) + BatteryActivity

**Files:** Create `Islet/Activities/Battery/BatteryMonitor.swift`, `Islet/Activities/Battery/BatteryActivity.swift`; Modify `DefaultsKeys.swift` (+`batteryEnabled`, default true), `SettingsView.swift` (Activities section), `AppDelegate.swift` (register)

- `BatteryMonitor`: reads snapshots via `IOPSCopyPowerSourcesInfo`/`IOPSGetPowerSourceDescription` (keys `kIOPSCurrentCapacityKey`, `kIOPSMaxCapacityKey`, `kIOPSIsChargingKey`, `kIOPSPowerSourceStateKey == kIOPSACPowerValue`); subscribes with `IOPSNotificationCreateRunLoopSource` on the main run loop (C callback → context pointer → instance). Publishes `@Published state: BatteryState?`.
- `BatteryActivity` (ambient): observes monitor; on each change runs the detector and submits sneaks — bolt.fill green + "N%" for connect, battery icon + "N%" for disconnect, red battery + "N%" for low. `isActive` = `batteryEnabled && (state?.isCharging ?? false)`; compact = green bolt (leading) / percent text (trailing); expanded = simple battery panel (icon, %, charging state).
- Settings: "Activities" section with Battery toggle. Registration in AppDelegate.

### Task 5: Track-change sneak + adapter status row

**Files:** Modify `NowPlayingActivity.swift`, `MediaWatcher.swift`, `SettingsView.swift`
