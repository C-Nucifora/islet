## M4 — HUD replacement

**Suppression mechanism (corrected from spec):** a `CGEventTap` on system-defined events *consumes* the volume/brightness media keys (returns `nil`), then applies the change itself. The system OSD never fires because the system never sees the key. This is **crash-safe by construction** — the tap lives only while Islet runs, so keys always revert on quit/crash. No `OSDUIHelper` suspension, no persistent state, no restore invariant needed. Requires Accessibility permission.

- **HUDKey** (pure, tested): decode `NSEvent.data1` → `(key, isKeyDown)`. keyCode = `(data1 & 0xFFFF0000) >> 16`, state = `(data1 & 0xFF00) >> 8` (0xA down / 0xB up). Map 0→volumeUp, 1→volumeDown, 7→mute, 2→brightnessUp, 3→brightnessDown. Step math: `stepped(value, up, divisor) = clamp(value ± (1/16)/divisor)`.
- **VolumeController** (CoreAudio): default output device, read/write `kAudioDevicePropertyVolumeScalar` (main element, fallback ch 1–4), mute via `kAudioDevicePropertyMute`.
- **BrightnessController** (DisplayServices via dlopen): `DisplayServicesGetBrightness`/`SetBrightness` on the main display. Degrades to no-op if the symbol is unavailable.
- **HUDController** (ObservableObject): owns the tap; `@Published hud: HUDSnapshot?` (icon + level 0…1 + isMute). On a handled keydown: apply change, set `hud`, schedule hide after 1.4 s. Re-enable tap on `tapDisabledByTimeout`/`ByUserInput`. `start()` no-ops unless `hudEnabled` && `AXIsProcessTrusted()`.
- **Render**: HUD outranks sneaks and activity compact content in `NotchRootView` (leading icon + trailing slim level bar).
- **Settings**: HUD toggle + "Grant Accessibility…" button (`AXIsProcessTrustedWithOptions` prompt) shown when not trusted.

## M5 — Calendar + AirPods

- **CalendarActivity** (EventKit): request full access; ambient priority. `isActive` when the next event starts within `calendarLeadMinutes` (default 10, Defaults key). Compact = clock icon + "Nm" countdown; expanded = today's remaining agenda (time, title, calendar color dot, tappable video-call URL). Degrades to off + Settings grant button when denied. Pure `CalendarLogic.nextRelevantEvent` + `countdownText` tested.
- **AudioDeviceActivity** (CoreAudio): watch default-output-device changes; on change to a new device submit a connect sneak (device icon + name). Battery percentage best-effort via IOKit/IOBluetooth; if unavailable, name-only (accepted risk). Not a persistent activity — sneak-only (registers no compact/expanded, `isActive` always false; drives sneaks directly).
- **Settings**: Calendar + AirPods toggles in Activities; calendar lead-time stepper.

## M6 — Polish

- **Multi-display**: `ScreenManager` builds a panel per screen when `showOnAllDisplays` (Defaults, default false); non-notch screens use the fallback geometry already in `NotchGeometry`. One `NotchViewModel` per screen; `viewModel` accessor returns the screen-with-mouse's VM for menu actions.
- **Fullscreen awareness**: hide the panel when the notch's screen has a fullscreen app (`NSWorkspace` active-space / window check); Defaults `hideInFullscreen` (default false).
- **Launch at login**: `SMAppService.mainApp` register/unregister via a `launchAtLogin` Defaults toggle.
- **Idle timeout** (deferred from M2): now-playing deactivates after 60 s paused.
